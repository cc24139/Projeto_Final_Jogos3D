# Instruções para assistentes
Leia README.md e docs/ antes de modificar o projeto.
Mantenha o escopo de Arena de Treinamento. Não acrescente features fora do escopo.
Use a versão registrada em ProjetoFinal3D/ProjectSettings/ProjectVersion.txt. Não atualize engine ou pacotes sem alinhamento do trio.
Preserve arquivos .meta e seus GUIDs. Não edite Library, Temp ou outros caches.
O integrante 1 cuida do personagem; o 2, da arena e inimigos; o 3, das regras e interface.
Somente o integrante 2 integra a cena principal. Cada integrante usa uma cena de teste própria.
As interfaces C# ainda não foram definidas. Documente um contrato comum antes de criar dependências entre os módulos.
Ao concluir, atualize docs/CONTINUIDADE.md com decisões, arquivos, testes, pendências e próximo passo. Não apresente testes não executados como aprovados.

O projeto Unity está em ProjetoFinal3D/. Use Input System 1.17.0, já ativo. Não usar a API antiga UnityEngine.Input. URP 17.3.0 já está instalado.
